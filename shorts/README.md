# Шортсы KinoMir360

Бот сам собирает вертикальный ролик 1080×1920 (~30 сек) и присылает админам в Telegram:
видео, обложку и SEO (название, описание, теги, закреплённый комментарий).

## Как это работает

- **Каждый день в 8:00 по Москве** (`SHORTS_HOUR`) — тема дня по расписанию:
  пн онлайн-премьеры, вт кинопрокат, ср 5 фактов о фильме, чт топ жанра, пт онлайн-премьеры,
  сб скоро в кино, вс 5 фактов о фильме. Если бот перезапустился после 8:00 и ролика сегодня ещё не было — соберёт сразу.
- Фильмы берутся из API Кинопоиска (тот же `KINOPOISK_TOKEN`, что у бота). Фильмы из роликов
  за последние 30 дней не повторяются (`shorts_history`).
- Картинки: кадры без надписей в высоком качестве — с TMDB (`tmdb.py`, ключ `TMDB_API_KEY`, тот же,
  что у бота); если на TMDB нет — фон и постер с Кинопоиска. Обложка — русский постер Кинопоиска.
- Карточки и обложка рисуются в стиле канала (`cards.py`), голос — бесплатный синтез Microsoft Edge
  (`edge-tts`), музыка — `assets/music.mp3` или загруженная командой `/music`.
- Если голос не синтезировался, ролик собирается только с музыкой, и бот об этом предупреждает.

## Команды (только для ADMIN_IDS)

- `/short` — собрать ролик сейчас (тема дня); `/short cinema` — с конкретной темой:
  `online`, `cinema`, `series`, `upcoming`, `genre`, `genre:ужасы`
  (фантастика, ужасы, триллер, комедия, боевик, детектив), `facts` — 5 фактов о случайном
  известном фильме, `facts Матрица` — о конкретном (факты из раздела Кинопоиска «Знаете ли вы»).
- `/music` — прислать аудиофайл с подписью `/music` (или ответить `/music` на сообщение с музыкой),
  чтобы сменить фоновую музыку. `/music default` — вернуть стандартную. Музыка — только без АП.

## Сборка вручную из своих картинок

```bash
python -m shorts.make_short путь/к/config.json
```

Пример конфига — `examples/premieres.json` (пути считаются от папки конфига).
`voice_segments` — текст озвучки по слайдам: смена слайдов идёт по паузам в голосе.
Вместо этого можно задать `"starts": [0, 5.5, ...]` — начало каждого слайда в секундах.
Прочие настройки: `header`, `tag`, `music_db`, `tail`, `watermark_width`, `watermark_opacity`,
`outro.question` (`\n` — перенос строки), `outro.youtube`, `outro.telegram`, `outro.note`.

Шрифты Oswald, Montserrat и PT Serif — Google Fonts, лицензия SIL OFL (`assets/OFL.txt`).
