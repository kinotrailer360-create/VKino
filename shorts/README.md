# Шортсы KinoMir360

`make_short.py` собирает вертикальное видео 1080×1920 (30 fps) из:

- обложки (`intro`) — первый слайд с медленным зумом;
- карточек фильмов (`cards`) — карточка на размытом фоне, заголовок, плашка «НОВИНКИ», прогресс-бар и подпись;
- голоса (`voice`) — синтез; смена слайдов идёт по паузам в речи;
- музыки (`music`) — без АП, приглушается под голос, громкость нормализуется до −14 LUFS;
- логотипа (`logo`) — водяной знак в углу и финальный экран с призывом подписаться на YouTube и Telegram.

## Запуск

```bash
pip install -r shorts/requirements.txt   # нужен ещё ffmpeg
python shorts/make_short.py путь/к/config.json
```

Пути в конфиге считаются от папки, где лежит сам конфиг. Пример: `examples/premieres.json`
(рядом с ним должны лежать `cover.jpg`, `card1..9.jpg`, `logo.jpg`, `voice.mp3`, `music.wav`,
шрифты `Oswald.ttf` и `Montserrat.ttf` из Google Fonts).

## Синхронизация с голосом

`voice_segments` — текст озвучки по слайдам: обложка, каждая карточка, финал.
Скрипт ищет паузы в голосе, ближайшие к ожидаемым по длине текста, и меняет слайд на них.
Если нужно задать вручную — укажите `"starts": [0, 5.5, 10.5, ...]` (секунды начала каждого слайда).

Прочие настройки: `header`, `tag`, `music_db` (громкость музыки, дБ), `tail` (хвост после голоса, сек),
`watermark_width`, `watermark_opacity`, `outro.question` (`\n` — перенос строки), `outro.channel`, `outro.note`.
