VKino — HDRezka button fallback

Что исправлено:
- Кнопка «▶️ Смотреть HDRezka» больше не исчезает, если Railway не смог
  автоматически распарсить HDRezka.
- Если точная страница фильма уже найдена/закэширована — кнопка открывает её.
- Если серверный поиск не сработал — кнопка открывает встроенный поиск HDRezka
  по названию и году.
- Все остальные функции VKino сохранены.

Загрузить в GitHub с заменой:
- bot.py

Остальные файлы можно не менять, если предыдущая версия уже загружена.

После Commit changes Railway должен получить новый commit.
Если автоматического деплоя нет:
Railway -> VKino -> Deployments -> Deploy latest commit / Redeploy.

Проверка:
Telegram -> /start -> найти старый известный фильм, например «Интерстеллар».
В карточке должна быть кнопка «▶️ Смотреть HDRezka» даже если в Deploy Logs
есть сообщение об ошибке автоматического определения страницы.
