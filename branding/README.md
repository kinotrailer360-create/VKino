# FootyVibe360 — как собирается ролик

1. **Исходники**: съёмки с трибун (без ТВ-трансляций). Разные ракурсы одного гола синхронизируются по моменту, когда мяч пересекает линию.
2. **Монтаж** 720×960, 30 fps, склейки по долям трека 140 BPM: розыгрыш → РАЗБОР → удар в слоу-мо → гол на дроп («ГОООЛ», вспышка, тряска, живой рёв трибун) → повтор с других камер → празднование → финальная карточка.
3. **Трек** — свой, генерируется (`music_gen.py`, без авторских прав), каждый раз новая тональность/seed.
4. **Разбор** — `telestrate.py` (луч+кольцо, стрелка паса/удара, лупа, заштрихованная зона) на стоп-кадре.
5. **Киношный режим** — `cinematic.sh` (тёмный грейд, лучи прожектора, туман, свечение). ✅ Решено: **добавлять со следующего ролика** — повтор гола «в кино» после обычного повтора + финальная карточка в дыму. ИИ-генерацию крупных планов пока не используем (платно).
6. **Shorts-оформление** 1080×1920: заголовок сверху, ник @FootyVibe360, размытый фон.
7. **Концовка** — `add_endcard.sh`: «лайк + подписка» после ролика, бесшовный повтор (последний кадр = первый).
8. **Обложка** — вшивается в ролик на 4 кадра в стоп-кадре разбора; при загрузке выбрать этот кадр.
9. **SEO** — vidIQ: ключи, оценка названий, EN-перевод названия, описание с вопросом к зрителям, закреп-опрос.

## Решения по подаче (с следующего ролика)
- ❌ Не писать про камеры: убрать «1 ГОЛ — N КАМЕР» из заголовка, карточки и названия; плашки «КАМЕРА N» не ставить.
- ✅ В центре — **автор гола**: заголовок сверху вида «ГОЛ МЕССИ» / «МЕССИ — ПАС АЛЬБЫ» (если известен ассистент), карточка в конце: имя автора + «пас: …» + матч.
- ✅ Название/описание/SEO строить вокруг игрока и ассистента, а не количества ракурсов.
