# FootyVibe360 — как собирается ролик

## ⚠️ ОБЯЗАТЕЛЬНЫЕ СТАНДАРТЫ (каждый ролик, без исключений — решения пользователя)
1. **Никакой дымки/тумана**: `cinematic.sh` только с FOG=0 (по умолчанию), карточки и переходы без дыма.
2. **Слежение за мячом**: `branding/balltrack.py` на атаке, ударе и slow-mo влёта + маркер над мячом в цвете клуба, исчезает при касании сетки.
3. **Сам гол хорошо виден**: влёт с ракурса у ворот, slow-mo 0.35–0.5x, зум к створу; на «ГОООЛ» мяч в сетке крупно; шейк/флеш/текст — только ПОСЛЕ касания сетки. Проверять кадрами.
4. Автор гола подтверждён по кадрам (номер/празднование) или ⚠️; ассистент — только если виден; без надписей про камеры; чужие подписи/водяные знаки убрать.

1. **Исходники**: съёмки с трибун (без ТВ-трансляций). Разные ракурсы одного гола синхронизируются по моменту, когда мяч пересекает линию.
2. **Монтаж** 720×960, 30 fps, склейки по долям трека 140 BPM: розыгрыш → РАЗБОР → удар в слоу-мо → гол на дроп («ГОООЛ», вспышка, тряска, живой рёв трибун) → повтор с других камер → празднование → финальная карточка.
3. **Трек** — свой, генерируется `music_styles.py` (без авторских прав). Стили: drill, funk, epic, house, phonk — **чередовать, не повторять стиль два ролика подряд**, плюс новая тональность/seed каждый раз.
4. **Разбор** — `telestrate.py` (луч+кольцо, стрелка паса/удара, лупа, заштрихованная зона) на стоп-кадре.
5. **Киношный режим** — `cinematic.sh` (тёмный грейд, слабые лучи прожектора, свечение). ❌ **Без дымки/тумана** (решение пользователя): fog-слой выключен по умолчанию, финальная карточка — без дыма, дымовые переходы не используем. ✅ Решено: **добавлять со следующего ролика** — повтор гола «в кино» после обычного повтора + финальная карточка (без дыма). ИИ-генерацию крупных планов пока не используем (платно).
5a. **Слежение за мячом (стандарт для каждого ролика)** — `balltrack.py`: виртуальная камера zoom 1.3–1.6× плавно едет за мячом на атаке, ударе и slow-mo влёта (точки мяча `{t,x,y}` по раскадровке каждые ~3–5 кадров → интерполяция + гауссово сглаживание, мяч чуть впереди по ходу, окно не выходит за кадр, субпиксельный кроп). Над мячом — треугольник в цвете клуба, исчезает в момент касания сетки (`--marker-end`). Пример — `autobot/templates/build_example_espart.py`.
6. **Shorts-оформление** 1080×1920: заголовок сверху, ник @FootyVibe360, размытый фон.
7. **Концовка** — `add_endcard.sh`: «лайк + подписка» после ролика, бесшовный повтор (последний кадр = первый).
8. **Обложка** — вшивается в **первые 2 кадра** ролика (0 с); при загрузке ползунок обложки — в самое начало.
9. **SEO** — бесплатно: `yt_suggest.py` (подсказки поиска YouTube, ru+en) → ключи в название/описание/теги; vidIQ — только если есть кредиты (оценка названий 5 кр., ключи; пополнение раз в месяц). EN-перевод названия, вопрос к зрителям, закреп-опрос.

## Решения по подаче (с следующего ролика)
- ❌ Не писать про камеры: убрать «1 ГОЛ — N КАМЕР» из заголовка, карточки и названия; плашки «КАМЕРА N» не ставить.
- ✅ В центре — **автор гола**: заголовок сверху вида «ГОЛ МЕССИ» / «МЕССИ — ПАС АЛЬБЫ» (если известен ассистент), карточка в конце: имя автора + «пас: …» + матч.
- ✅ Название/описание/SEO строить вокруг игрока и ассистента, а не количества ракурсов.
