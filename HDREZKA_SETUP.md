# VKino + HDRezka provider — установка

Обновление добавляет HDRezka как дополнительный источник для существующего VKino-плеера.
Существующие TMDb, YouTube, Blender Open Movies, напоминания, история, статистика,
внешний VIDEO_PROVIDER_API и fullscreen остаются.

## Что загрузить в GitHub

В корень репозитория `kinotrailer360-create/VKino` загрузить с заменой:

- `bot.py`
- `requirements.txt`

И добавить новый файл:

- `hdrezka_provider.py`

После Commit Railway должен автоматически пересобрать сервис.

## Railway Variables

Открой Railway -> VKino -> Variables и добавь:

```text
HDREZKA_ENABLED=true
HDREZKA_MIRROR=https://ВАШ_РАЗРЕШЕННЫЙ_ДОМЕН_ИЛИ_ЗЕРКАЛО
HDREZKA_DEFAULT_VOICE=Дубляж
HDREZKA_MAX_VOICES=8
HDREZKA_REFRESH_MINUTES=30
```

### Пояснения

- `HDREZKA_ENABLED` — включает провайдер.
- `HDREZKA_MIRROR` — разрешённый домен/зеркало. Если оставить пустым, библиотека использует свой домен по умолчанию.
- `HDREZKA_DEFAULT_VOICE` — только приоритет в списке озвучек; остальные доступные озвучки тоже остаются. Можно оставить пустым.
- `HDREZKA_MAX_VOICES` — сколько непремиальных озвучек максимум загружать на один фильм/эпизод. Рекомендуется 6–10.
- `HDREZKA_REFRESH_MINUTES` — через сколько минут обновлять временные видеоссылки. Минимум 5.

Реальные токены/пароли в GitHub не добавлять.

## Как работает

1. Пользователь открывает фильм или серию в VKino.
2. Mini App вызывает `/api/playback`.
3. Если HDRezka включена и свежих HDRezka-источников нет, бот:
   - получает название/год из ПоискКино;
   - находит максимально близкое совпадение;
   - получает доступные непремиальные озвучки;
   - получает 360/480/720/1080;
   - добавляет их во временный playback-каталог VKino.
4. Mini App показывает обычный выбор `Озвучка -> Качество`.
5. Уже существующие ручные/Blender/API-источники не удаляются.

## Сериалы

VKino продолжает брать структуру сезонов и серий из ПоискКино.
При открытии конкретной серии HDRezka-провайдер пытается выбрать соответствующий сезон и эпизод,
после чего формирует варианты озвучек и качества для этой серии.

## Проверка после деплоя

В Railway Logs должны появиться строки примерно:

```text
PostgreSQL connected
VKino Mini App server started on port 8080
VKino started
HDRezka provider: enabled
```

Затем в Telegram:

1. `/start`
2. Найти уже вышедший фильм.
3. Открыть карточку.
4. Нажать `▶️ Смотреть`.
5. Подождать первый запуск — он может быть заметно дольше обычного, потому что бот ищет источник и озвучки.
6. Проверить список озвучек и 360/480/720/1080.

Для сериала: открыть `📺 Сезоны и серии` -> конкретную серию -> `▶️ Смотреть серию`.

## Если источник временно недоступен

Бот не должен падать. Он оставит существующие источники и вернёт обычное сообщение Mini App
`Источники не найдены`, если ни один провайдер не смог дать поток.
