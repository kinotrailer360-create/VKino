# Харчо — 30-секундный анимационный кулинарный ролик

Процедурная анимация на Canvas 2D (без внешних картинок), русская озвучка Piper,
оригинальная музыка и звуковые эффекты, синтезированные из PCM.

| Файл | Что это |
|---|---|
| `kharcho_final.mp4` | готовое видео: 1920×1080, 30 fps, 30,0 с, H.264 High + AAC 48 кГц стерео |
| `kharcho_animation.js` | анимация: таймлайн (`SCENES`, `CAPTIONS`, `CARDS`, `VOICE`, `SFX`), сцены, процедурные текстуры |
| `kharcho_music.wav` | фоновая музыка (6/8, ля минор, «пандури», бурдон, свирель, доли), 30,0 с |
| `kharcho_voice.wav` | озвучка, фразы стоят на своих отметках, 30,0 с |
| `kharcho_sfx.wav` | кипение, шипение сковороды, вливание, «плюх» мяса, свисты переходов |
| `kharcho_contact_sheet.jpg` | контактный лист: 25 кадров с шагом 1,25 с и последний кадр |
| `kharcho_audio.js` | синтез музыки и эффектов |
| `kharcho_voice.py` | синтез озвучки и проверка, что фразы не налезают и помещаются в 30 с |
| `render.js` | съёмка кадров через Playwright: кадр *n* рисуется ровно при t = n/30 |
| `build.sh` | полная сборка: звук → озвучка → кадры → сведение и кодирование FFmpeg → контактный лист |
| `index.html` | страница анимации; открытая без `?render` проигрывает ролик в реальном времени |

## Сборка

```bash
pip install piper-tts numpy
python3 -m shorts.get_voice /opt/piper    # из корня репозитория: голос ru_RU-dmitri-medium
./kharcho/build.sh                        # ~5 минут на 4 ядрах
SKIP_FRAMES=1 ./kharcho/build.sh          # только звук и перекодирование из готовых кадров
```

Предпросмотр: `npx http-server .` в корне репозитория и открыть `/kharcho/index.html`
(шрифты Montserrat и PT Serif берутся из `shorts/assets`).

## Как редактировать

Всё время задаётся в начале `kharcho_animation.js`:

- `SCENES` — сцены с точными границами и типом перехода (`whip` / `zoom`);
- `CAPTIONS`, `CARDS` — подписи и карточки с ингредиентами;
- `VOICE` — фразы диктора и моменты начала; `tts` — текст для синтеза, если нужно
  поправить ударение фонемами Piper, например `[[kʲinzˈu]]`;
- `SFX` — звуковые эффекты с интервалами и громкостью.

Сведение (громкость музыки, приглушение под голос, лимитер) — в `build.sh`.
