# Ночная сборка FootyVibe360 — инструкция для сессии по расписанию

Цель: к утру прислать в Telegram готовые Shorts + SEO из видео, которые пользователь переслал боту за день.

## ⚠️ ОБЯЗАТЕЛЬНЫЕ СТАНДАРТЫ (каждый ролик, без исключений — решения пользователя)
1. **Никакой дымки/тумана**: `cinematic.sh` только с FOG=0 (по умолчанию), карточки и переходы без дыма.
2. **Слежение за мячом**: `branding/balltrack.py` на атаке, ударе и slow-mo влёта + маркер над мячом в цвете клуба, исчезает при касании сетки.
3. **Сам гол хорошо виден**: влёт с ракурса у ворот, slow-mo 0.35–0.5x, зум к створу; на «ГОООЛ» мяч в сетке крупно; шейк/флеш/текст — только ПОСЛЕ касания сетки. Проверять кадрами.
4. Автор гола подтверждён по кадрам (номер/празднование) или ⚠️; ассистент — только если виден; без надписей про камеры; чужие подписи/водяные знаки убрать.

## 0. Проверки
- `python3 autobot/tg.py me` — токен (переменная `TELEGRAM_BOT_TOKEN`), домен `api.telegram.org` разрешён.
- Работать в ветке репозитория, коммитить результат; токен никогда не коммитить. `autobot/state.json` коммитить (offset).

## 1. Забрать видео
`python3 autobot/tg.py pull inbox` → `inbox/<дата>/manifest.json` (файлы, подписи, chat_id).
Нет новых видео → отправить короткое «Новых видео нет» и перейти к шагу 5 (подборка голов).

## 2. Разобрать
- Сгруппировать видео по голу (подписи, media_group, одинаковый стадион/табло, время). Дубликаты (одинаковые кадры) отбросить.
- В каждой группе: найти момент «мяч в сетке» (кадры + всплеск громкости трибун), камеры синхронизировать по нему.
- Отсеять ТВ-трансляции (графика каналов поверх, логотипы) и чужие водяные знаки/подписи (обрезать/размыть).
- Автор гола: из подписи пользователя → иначе по празднованию/номеру. Не уверен — так и написать в сообщении и спросить.

## 3. Собрать ролик (правила — `branding/README.md`)
- Монтаж 720×960 по долям 140 BPM: розыгрыш → РАЗБОР (`branding/telestrate.py`) → удар слоу-мо → гол на дроп → повторы с других камер → КИНО-повтор (`branding/cinematic.sh`) → празднование → финальная карточка (без дыма/тумана). Слежение за мячом (`branding/balltrack.py`) на атаке/ударе/влёте — обязательно. Влёт мяча в сетку должен читаться: ракурс у ворот, slow-mo, зум, кольцо на мяче, шейк/флеш только после сетки.
- **Без «камер»**: заголовок — автор гола / счёт / «пас: …».
- Музыка: `branding/music_styles.py`, стиль НЕ как в прошлом ролике (журнал в README), новый key/seed; рёв трибун под дроп.
- Shorts 1080×1920 → `branding/add_endcard.sh` → **обложка в первые 2 кадра**.
- Проверить кадры (контакт-лист) и громкость (нет тишины), стык повтора.

## 4. SEO и отправка
- Ключи: `python3 branding/yt_suggest.py "<игрок> гол" "<player> goal" "<клуб>"`; название (рус) + EN-перевод, описание, теги, закреп.
- Сохранить `<ролик>.mp4` + `<ролик>.md`, коммит + push.
- `tg.py send-video <chat_id> ролик.mp4 "<название>"`, затем **`tg.py send-seo <chat_id> ролик.md`** — шлёт чистые сообщения (каждое — отдельным сообщением: ⚠️ проверить / 📌 название / 🔁 запасные / 🇬🇧 перевод / 📝 описание / 🏷 теги / 📍 закреп; у коротких — кнопка «📋 Копировать») с копированием по нажатию. `send-text` для SEO не использовать — это сырая разметка («каша»). ## 5. Подборка свежих голов на сегодня
- Если есть кредиты vidIQ (≥5): один поиск съёмок голов с трибун за последние 24–48 ч → 3–5 ссылок с описанием.
- Отправить списком: «Свежие голы с трибун — скачай 2–4 ракурса и перешли мне».
