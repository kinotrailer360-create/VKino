# Шаблоны монтажа (рабочие скрипты, которыми собраны ролики)
- `build_template.py` — последний эталон (гол Месси 0:2): сегменты в долях 140 BPM, готовые FILE:-сегменты для РАЗБОРА/КИНО/карточки, без плашек «КАМЕРА».
  Запуск: `python3 build_template.py <главный_исходник> out.mp4 src0,src1,...` (W = папка скрипта: туда же класть track_*.wav и *seg.mp4).
  Перед запуском: поменять список seg(...) (тайм-коды исходников), PLATE (имя/номер/цвета клуба), имя трека.
- `build_example_yamal.py` — пример с 4 камерами.
- Полный порядок (разбор → кино → карточка → микс рёва трибун → Shorts 1080×1920 → add_endcard.sh → обложка в первые 2 кадра) — см. команды в истории и `autobot/NIGHTLY.md`.
- Сборка Shorts-кадра: заголовок сверху fontsize ~88 InterDisplay-BlackItalic, полосы цвета клуба на y=226 и y=1670, видео 1080×1440 на y=230 поверх размытого фона.
