# VKino — эксплуатация AI-производства

Установка, обновление, бэкапы и откат сервера — в [`deploy/README.md`](../deploy/README.md). Здесь — то, что
относится к сборке роликов, проверкам и согласованиям.

## Где что лежит

| Что | Где |
|---|---|
| Готовые ролики и их проекты (правка «Только звук», «Полностью», сцены) | том `data`: `/data/ready/<чат>/<сообщение>/` — `project.json`, `scene_plan.json`, карточки, отрывки, голос; хранятся `READY_DAYS` дней |
| Утверждения сцен | таблица `scene_approvals` (версия сцены = отпечаток текста, времени и файла) |
| Журнал действий (публикация, утверждения) | таблица `ai_audit_log` |
| Черновики постов, отложка, однократная публикация | `ai_drafts`, `ai_queue` |
| Расходы на платные ИИ | таблица `ai_usage` (лимиты — `shorts/budget.py`) |
| Кэш озвучки | том `data`, `voice_cache` — повторная сборка платит только за новые фразы |

## Ключи (только в `/opt/vkino/deploy/.env`, никогда в чат и в код)

`BOT_TOKEN`, `ADMIN_IDS`, `KINOPOISK_TOKEN`, `TMDB_API_KEY`, `GEMINI_API_KEY`, `RESERVE_AI_KEY`, `LUMEAN_*`,
`GROQ_API_KEY`, `TAVILY_API_KEY`, `YANDEX_KEY` (поиск), `NITTER_URL` / `RSSHUB_URL` (X). Без ключа функция
отключается с понятным сообщением, а не подменяется выдумкой.

## Процесс ролика «Факты о фильме»

1. Сбор фактов → сверка каждого факта с Википедией, Кинопоиском и постами каналов (`ai.check_facts`).
2. Подбор кадров: свои материалы → Telegram-каналы → портрет из состава фильма → трейлер (≥75/100) → кадр
   TMDB/Кинопоиска (≥70/100) → поиск картинок → ИИ-иллюстрация (до 5) → постер. У каждого — источник и права.
3. Сборка → автопроверка (`shorts/qc.py`) → ролик автору с отчётом.
4. «🖼 Проверить сцены»: у каждой — кадр/отрывок, источник, права, статус факта; «✅ Утвердить сцену» или
   «🔄 Заменить» (фото или видео). Замена → перемонтаж → утверждение снимается только с заменённой сцены.
5. Все сцены утверждены → кнопки публикации. Публикация — отдельным нажатием, один раз (`_claim_publish`).

Свой сценарий / задание: текст → «🎙 Сначала послушать озвучку» (исправления через `/say`) → «✅ Собрать».

## Если что-то не так

| Симптом | Где смотреть |
|---|---|
| «Не скачались картинки» | причина в самом сообщении (DuckDuckGo/Bing); логи: `docker compose logs --tail 200 bot \| grep "image search"` |
| Факты все «⚠️ не подтверждён» | ИИ сверки не ответил (лимит/ключ): `grep "fact check failed"` в логах |
| «🧪 проверка не запустилась» | нет ffmpeg/ffprobe в контейнере или битый файл |
| Сцены не утверждаются | миграция 008 не применилась: `docker compose exec db psql -U vkino -c "select * from schema_version"` |
| Пост с чужим именем | под постом «⚠️ Этих имён нет в источниках»; сверка — `ai.ungrounded_names` |

## Тесты

`python -m pytest -q` — модульные и сквозной тест согласования сцен с заглушками Telegram и базы (в канал
ничего не публикуется). Живые ИИ, поиск и Telegram в тестах не вызываются — их проверяют сборкой на сервере.
