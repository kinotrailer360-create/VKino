# VKino Studio for Windows — MVP 0.1

Это отдельная программа для локального монтажа утверждённых фото/видео и озвучки. В существующих файлах bot.py и shorts/ ничего не изменено. Первая версия не подключается к VPS, не выполняет поиск кинокадров и ничего не публикует.

## Уже реализовано

- Запуск Windows GUI командой python -m vkino_studio.
- Формат 9:16: 360x640 (для тестов), 720x1280 и 1080x1920; 24/25/30 FPS.
- Кадры из локальных JPEG/PNG/WEBP и MP4/MOV/MKV/WEBM, отдельная аудиодорожка каждой сцены.
- Верхняя плашка, жёлтые субтитры по 1–2 слова, H.264 и AAC, объединение сцен в MP4.
- По умолчанию libx264; дополнительный h264_nvenc для совместимых драйверов GTX 1070.
- Проверка approved=true у каждой сцены. Запрещены внешние URL, абсолютные пути и зацикливание коротких видео.
- Выходные файлы vkino_studio_preview.mp4 и render_report.json с отметкой, что окончательное утверждение и публикация не выполнялись.

**Ограничения:** тайминг субтитров сейчас оценочный, не выровнен по словам с аудио. Сцены должны быть выбраны и утверждены автором: ИИ-поиск актёров, проверка прав и точное соответствие озвучке ещё не реализованы. Локальные тесты выполнены на Linux с FFmpeg, проверка на Windows 10 и GTX 1070 впереди.

## Запуск на Windows

1. Установить Python 3.12; проверить, что работает py -3.12.
2. Установить FFmpeg с фильтром ass, добавить ffmpeg.exe и ffprobe.exe в PATH.
3. Открыть PowerShell в корневой папке репозитория и выполнить:

~~~powershell
py -3.12 -m venv .venv-studio
.venv-studio\Scripts\python.exe -m pip install Pillow
.venv-studio\Scripts\python.exe -m vkino_studio
~~~

Для консольной сборки:

~~~powershell
.venv-studio\Scripts\python.exe -m vkino_studio --project C:\VKinoProjects\demo\project.json --output C:\VKinoProjects\demo\output
~~~

## Формат проекта

JSON располагается в одной папке со всеми вложенными исходниками. Пути к исходникам относительные.

~~~json
{
  "version": 1,
  "title": "KinoMir360 — тест",
  "width": 1080,
  "height": 1920,
  "fps": 30,
  "captions": true,
  "scenes": [
    {
      "source": "media/scene01.jpg",
      "voice": "voice/scene01.wav",
      "text": "Начинаем новости кино сегодня",
      "headline": "ГЛАВНАЯ НОВОСТЬ",
      "duration": 3.2,
      "start": 0,
      "rights": "author",
      "approved": true
    }
  ]
}
~~~

Для видео source может указывать на media/scene01.mp4, а start — на время начала фрагмента. Видео должно быть длиннее start + duration, голос — не длиннее duration. До 30 сцен и 180 секунд. Статус rights=unconfirmed учитывается в отчёте, но не подтверждает право публикации.

## Тестирование

~~~powershell
.venv-studio\Scripts\python.exe -m pip install pytest
.venv-studio\Scripts\python.exe -m pytest -q tests/test_vkino_studio.py
~~~

Тесты синтезируют собственное видео/аудио, не используют облачные ключи.

## Следующий этап — интеграция с VKino

1. Создать на VPS отдельную очередь studio_worker_jobs с версией проекта и идентификатором задания. Существующие очереди VKino оставить без изменений.
2. Сделать отдельный ключ Windows-воркера с возможностью отзыва/ротации, хранить хеш на VPS, HTTPS обязательно. Не передавать BOT_TOKEN, админские ключи и учётные данные PostgreSQL.
3. Windows-воркер сам забирает утверждённые задачи исходящим запросом к VPS. Никаких открытых портов домашнего роутера.
4. Передавать исходные медиа потоково, с проверкой SHA-256 и ограничениями размера. Не пропускать большие видео через память VPS.
5. Возвращать предпросмотр к авторскому согласованию. Изменение сцены должно сбрасывать старое утверждение. Публикация — отдельное подтверждаемое действие.
6. Переключать тяжелые задания на ПК только после тестов интеграции и сохранения резервного рендера на VPS.

Документ описывает MVP, а не финальную готовую программу.
