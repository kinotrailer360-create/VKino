## 3. Функции (по коду)

**Пользовательские:** поиск фильмов и где смотреть, избранное, история, напоминания о премьерах, оценки,
викторина, дуэли и прогнозы, дневник, рефералы, «найди фильм по описанию» (`ai.guess_films`).

**Административные (ADMIN_IDS):**
- посты канала: новости (Telegram-каналы + быстрые зарубежные источники `/fast`), подборки, факты, опросы, RT;
  черновик → кнопки → `publish_post`;
- Shorts: факты о фильме (Smart Visuals: план сцен, проверка, замена кадра), подборки, «что мы знаем»,
  обзор, свой сценарий / задание (`lore`), еженедельный выпуск 16:9 по блокам;
- правка готового ролика: «Только звук», «Полностью», сцены (`shorts/project.py`);
- загрузка на YouTube/VK по кнопке; контент-план с напоминаниями (`shorts/plan.py`).

## 4. Поток данных и точки согласования

```
Telegram (callback/команда) → bot.py обработчик (проверка ADMIN_IDS) → shorts.* (ИИ, поиск, медиа)
  → файлы сборки (SHORTS_DIR) → project.json + scene_plan.json в /data/ready/<чат>/<сообщение>
  → ролик/пост автору в личку → [кнопки] → publish_post (канал) / загрузка YouTube
```

- **Публикация уже закрыта шлюзом:** в канал пост уходит только по кнопке администратора или по отложке,
  которую он поставил (`ai_queue`). Публикация однократна: `_claim_publish` (статус `publishing` → `published` /
  `failed`) в `ai_drafts`, действия — в `ai_audit_log`. Автопубликации без человека в коде нет.
- **Shorts «Факты»:** пока сцены не подтверждены (`scene_plan.json`, `review_mode`), кнопка публикации не
  показывается. Подтверждение — одной кнопкой на все сцены, хранится в файле, а не в БД.
- **Остальные ролики** (свой сценарий, подборки, выпуск) поэтапного согласования не имеют: ролик собирается
  целиком и показывается автору; правка — пересборкой.

| Ошибка | Подтверждённая причина | Исправление | Статус |
|---|---|---|---|
| «Супергёрл с Миллой Йовович» в посте | ИИ спутал похожие имена (Милли Олкок), фактчекер-ИИ не поймал | детерминированная сверка имён с источниками + исправление/предупреждение (`ai.ungrounded_names`) | в main (#220) |
| Кадры растянуты/обрезаны в 9:16 | обрезка горизонтального кадра под вертикаль | кадр целиком на размытом фоне (#215, #217) | в main |

| «Проекта нет» после обновления | проекты лежали в /tmp контейнера | перенос в том /data (#216) | в main |
| Картинки по ссылкам Google не скачиваются | Google не отдаёт выдачу ботам | DuckDuckGo → Bing + выбор Gemini, причина в сообщении (#219) | в main, **на сервере не проверено** |
| Наложение двух голосов в выпуске | старая и новая озвучка блока смешивались | блочная сборка (#205) | в main |
| Ударения игнорируются | модель eleven_multilingual_v2 не учитывает знак ударения | — | **открыто**; гипотеза: `eleven_v3` (стоит в .env как тест) |

**Непроверенные гипотезы** (нужны примеры с сервера):
1. Фото «не того» актёра в фактах: портрет выбирается по совпадению имени (`daily._mentioned_person`), без связи
   «актёр — роль — фильм» → однофамильцы и похожие имена.
2. Кадр не соответствует фразе в «своём сценарии»: Gemini выбирает по кадрам с шагом 1 с; при бедном пуле
   берётся «лучший из плохих» (порог есть не во всех режимах).
3. Факты без источника в «Фактах о фильме» из интернета: ссылки на источник не сохраняются к каждому факту.

## 7. Пробелы относительно ТЗ

| Требование ТЗ | Сейчас | Размер работы |
|---|---|---|
| Этапы A→B→C→D с утверждением каждой версии | только итоговый ролик; в «Фактах» — проверка сцен одной кнопкой | большой |
| Утверждение каждой сцены отдельно, версии сцен | нет; замена кадра пересобирает весь ролик | большой |
| Факт ↔ источник ↔ дата проверки ↔ статус | источник показан автору под постом, в БД не хранится | средний |
| Права и лицензии медиа, блок публикации при неизвестных правах | происхождение (`asset_source`) есть, лицензий нет | средний + **решение владельца** (см. ниже) |
| Согласования в БД, а не в файлах/кнопках | частично (`ai_drafts`, `ai_audit_log`); сцены — в JSON | средний |
| Автоматический QC (чёрные/застывшие кадры, клиппинг, длительность) | нет, кроме отдельных подрезок | средний |
| Каталог сущностей актёр—роль—произведение | нет своего; берётся из Кинопоиска/TMDB на лету | средний |
| Шлюз публикации на версию и канал | есть однократность и ручная кнопка; привязки к версии нет | малый |

**Решение, которое нужно от владельца.** Почти все кадры канала — постеры, кадры TMDB/Кинопоиска и отрывки
трейлеров; их лицензия неизвестна. Если строго следовать §6 и §11 ТЗ («права неизвестны — публиковать нельзя»),
публикация остановится полностью. Варианты: (а) записывать источник и помечать «права не подтверждены», но не
блокировать (как сейчас, это обычная практика обзорных каналов); (б) блокировать только ИИ-генерацию и чужие фото
людей без источника; (в) строгая блокировка.
